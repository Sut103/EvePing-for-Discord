# Task: 興味ありユーザーのページネーション取得

## Description

`internal/batch` パッケージに、`discordclient.Client.EventUsers` をページネーションしながら繰り返し呼び出し、あるイベントの「興味あり」ユーザー全件を取得する `FetchAllInterestedUsers(client discordclient.Client, guildID, eventID string) ([]discordclient.User, error)` を実装する。1回のAPI呼び出しは最大100件・`after`カーソル方式である前提で、返り件数が上限未満になるまでループする。

## Acceptance Criteria
- [ ] 興味ありユーザーが0人のイベントで、空リストが返る
- [ ] 興味ありユーザーが1ページ（100件未満）で収まる場合、1回のAPI呼び出しで全件取得できる
- [ ] 興味ありユーザーが複数ページにまたがる場合、`after`カーソルを更新しながら複数回呼び出し、全件を漏れなく取得できる
- [ ] API呼び出しがエラーを返した場合、エラーが呼び出し元に伝播する

## Test Plan
- [ ] フェイククライアントが0件を返すケースで空リストが返ることを確認するテスト — 「0人の場合、空リスト」を担保
- [ ] フェイククライアントが1ページ分（上限未満）を返すケースで1回の呼び出しで完了することを確認するテスト — 「1ページで収まる場合」を担保
- [ ] フェイククライアントが複数ページ（例: 100件+100件+30件）を返すケースで、全230件が重複・漏れなく取得できることを確認するテスト — 「複数ページにまたがる場合」を担保
- [ ] フェイククライアントが途中でエラーを返すケースで、そのエラーがそのまま返ることを確認するテスト — 「エラーが伝播する」を担保

## Technical Details

- ページサイズ上限は100固定とする（Discord APIの仕様に合わせる）。
- ループ終了条件: 直近の呼び出しで返った件数がページサイズ未満だった場合に終了する。
- `after` カーソルには直近ページ最後のユーザーIDを使う。
