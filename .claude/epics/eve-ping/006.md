# Task: バッチ実行の統合（RunDailyBatch）

## Description

`internal/batch` パッケージに、Task 2〜5の各部品を組み合わせて1回分の日次バッチを実行する `RunDailyBatch(client discordclient.Client, now time.Time) BatchResult` を実装する。全ギルドを走査し、各ギルドで対象イベントを抽出し、各イベントの興味ありユーザー全件を取得し、各ユーザーへリマインドDMを送信する。個別の失敗（1ギルドのイベント取得失敗、1ユーザーへの送信失敗）が他のギルド・イベント・ユーザーへの処理に波及しないことを保証し、成功数・失敗数を集計した `BatchResult` を返す。

## Acceptance Criteria
- [ ] 複数ギルド・複数対象イベント・複数ユーザーが存在するケースで、全ての組み合わせにDM送信が試行される
- [ ] あるギルドのイベント取得がエラーになっても、他のギルドの処理は継続される
- [ ] あるユーザーへのDM送信が失敗しても、同一イベントの他ユーザー・他イベントへの送信は継続される
- [ ] `BatchResult` に送信成功数・送信失敗数・処理対象イベント数が正しく集計される

## Test Plan
- [ ] 複数ギルド×複数イベント×複数ユーザーの正常系で、全組み合わせにSendDMが呼ばれることを確認するテスト — 「全ての組み合わせにDM送信が試行される」を担保
- [ ] 1ギルドでScheduledEvents取得がエラーを返すケースで、他ギルドの処理結果が正常に集計されることを確認するテスト — 「他のギルドの処理は継続される」を担保
- [ ] 1ユーザーへのSendDMがエラーを返すケースで、同イベントの他ユーザー・他イベントへの送信が実行されることを確認するテスト — 「他ユーザー・他イベントへの送信は継続される」を担保
- [ ] 成功数・失敗数・対象イベント数がフェイククライアントの応答から正しく計算されることを確認するテスト — 「BatchResultの集計が正しい」を担保

## Technical Details

- `BatchResult` 構造体案: `{ TargetEvents int; SentSuccess int; SentFailure int; Errors []error }`
- ループはgoroutineを使わず、シンプルな逐次forループとする（v1では並列化しない、epicの方針どおり）。
- Task 2（FilterTargetEvents）、Task 3（FetchAllInterestedUsers）、Task 4（FormatReminder）、Task 5（SendReminderDM）をこの関数内で呼び出して結合する。
