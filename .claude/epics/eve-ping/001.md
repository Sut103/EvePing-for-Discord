## Technical Details

- インターフェース案:
  ```go
  type Client interface {
      Guilds() []Guild
      ScheduledEvents(guildID string) ([]Event, error)
      EventUsers(guildID, eventID, after string, limit int) ([]User, error)
      SendDM(userID, message string) error
  }
  ```
- `Guild`, `Event`, `User` はdiscordgoの型に依存しない内部ドメイン型として定義し、discordgo実装側でマッピングする（他タスクがdiscordgoに直接依存しないようにするため）。
- `Event` には少なくとも ID、Name、ScheduledStartTime、Status、GuildID、URLを組み立てるための情報を含める。
