# Task: DM送信 + 個別エラーハンドリング

## Description

`internal/batch` パッケージに、1ユーザーへのDM送信を試み、失敗した場合はエラーを呼び出し元に返す（パニックしない）ラッパー `SendReminderDM(client discordclient.Client, userID, message string) error` を実装する。このタスクでは単一送信の責務のみを扱い、複数ユーザーに対するループでの継続処理はTask 6（統合）で扱う。

## Acceptance Criteria
- [ ] DM送信が成功した場合、エラーなくnilが返る
- [ ] DM送信がエラー（例: エラーコード50007 = DM拒否）を返した場合、そのエラーがラップされずに（または文脈情報を付加して）呼び出し元に返る
- [ ] 送信失敗時にpanicしない

## Test Plan
- [ ] フェイククライアントが成功を返すケースでnilが返ることを確認するテスト — 「送信成功時にnil」を担保
- [ ] フェイククライアントがエラーコード50007相当のエラーを返すケースで、そのエラーが呼び出し元に伝播することを確認するテスト — 「失敗時にエラーが返る」を担保
- [ ] フェイククライアントがエラーを返すケースでもテストプロセスがpanicせず正常終了することを確認するテスト — 「panicしない」を担保

## Technical Details

- `discordclient.Client.SendDM` の戻り値エラーをそのまま返すシンプルな実装でよいが、後続タスク（Task 6）でログに事情を残せるよう、userID・エラー内容を含むエラーメッセージにラップする。
