# Task: スケジューラ + エントリポイント結線

## Description

`internal/scheduler` に `time.Ticker` を使って24時間ごとに `RunDailyBatch` を呼び出す常駐ループを実装し、`cmd/eveping/main.go` で環境変数からBotトークンを読み込み、discordgoセッションを開始し、スケジューラを起動するエントリポイントを実装する。バッチの開始・終了、対象イベント数、成功/失敗件数をログに出力する。

## Acceptance Criteria
- [ ] `time.Ticker` により24時間周期で `RunDailyBatch` が呼び出される
- [ ] Botトークンが環境変数から読み込まれ、未設定の場合は起動時にエラーで終了する
- [ ] バッチ実行のたびに開始・終了・対象イベント数・成功数・失敗数がログに出力される
- [ ] `go build ./cmd/eveping` でバイナリがビルドできる

## Test Plan
- [ ] スケジューラのティッカーロジックに対し、時刻を進める（fake clockまたは短いintervalを注入する）テストで、指定回数だけ `RunDailyBatch` 相当のコールバックが呼ばれることを確認するテスト — 「24時間周期で呼び出される」を担保
- [ ] Botトークン環境変数が未設定の場合に起動処理がエラーを返すことを確認するテスト — 「未設定の場合エラーで終了する」を担保
- [ ] `BatchResult` を渡した際に期待するログ文言（対象イベント数・成功数・失敗数を含む）が出力されることを確認するテスト — 「ログに出力される」を担保

## Technical Details

- スケジューラの周期はテスト時に注入可能な設計にする（`NewScheduler(interval time.Duration, run func())` のようにintervalを外部から渡せるようにし、本番では24時間、テストではミリ秒単位を指定する）。
- ログ出力は標準の `log` パッケージで十分。構造化ログが必要になれば別途検討する（v1ではスコープ外）。
