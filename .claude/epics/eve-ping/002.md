# Task: イベントフィルタリングロジック

## Description

`internal/batch` パッケージに、イベント一覧から「明日（UTC基準）開始」かつ「ステータスがSCHEDULEDまたはACTIVE」のイベントだけを抽出する純粋関数 `FilterTargetEvents(events []discordclient.Event, now time.Time) []discordclient.Event` を実装する。Discord APIへの依存を持たない純粋関数とし、日付境界とステータスの分岐を網羅的にテストする。

## Acceptance Criteria
- [ ] 開始日時が「今日」「翌日」「翌々日」「前日」のイベントのうち、「翌日」のものだけが抽出される（UTC基準）
- [ ] ステータスが `CANCELED` または `COMPLETED` のイベントは、開始日が翌日であっても抽出されない
- [ ] ステータスが `SCHEDULED` または `ACTIVE` のイベントは抽出される
- [ ] 入力が空リストの場合、空リストを返す

## Test Plan
- [ ] 開始日が翌日・status=SCHEDULEDのイベントが抽出されることを確認するテーブル駆動テスト — 「翌日のものだけが抽出される」を担保
- [ ] 開始日が今日/翌々日/前日のイベントが除外されることを確認するテスト — 「翌日のものだけが抽出される」を担保
- [ ] status=CANCELED/COMPLETEDのイベントが翌日開始でも除外されることを確認するテスト — 「CANCELED/COMPLETEDは抽出されない」を担保
- [ ] status=SCHEDULED/ACTIVEのイベントが抽出されることを確認するテスト — 「SCHEDULED/ACTIVEは抽出される」を担保
- [ ] 空リスト入力で空リストが返ることを確認するテスト — 「空リストの場合、空リストを返す」を担保

## Technical Details

- 日付比較は `now.UTC()` の年月日と `event.ScheduledStartTime.UTC()` の年月日を比較し、差が1日であるものを対象とする（時刻は無視し日付のみで比較）。
- `now` を引数として受け取ることで、テスト時に任意の「現在時刻」を固定できるようにする（`time.Now()` を関数内で直接呼ばない）。
